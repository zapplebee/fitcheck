# fitcheck

Hono web dashboard and MCP server for personal nutrition and workout tracking.

Route:

`https://fitcheck.dev.prettybird.zapplebee.online`

MCP endpoint:

`https://fitcheck.dev.prettybird.zapplebee.online/mcp`

Developer-mode OAuth/DCR endpoints are intentionally lightweight and single-user oriented. Configure `FITCHECK_ACCESS_TOKEN` in `.env` for bearer access.
